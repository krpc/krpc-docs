# KSA API: v2026.11.10.5801 Additions

**Status:** in progress. Phases 1 to 4 are built and tested in game, not yet in a PR. Follows [api-coverage.md](api-coverage.md), whose service rules apply. Audited
by diffing the decompiled `KSA.dll` of builds 2026.10.25.5707 and 2026.11.10.5801.

Build 5801 adds life support, kitten condition and death causes, habitat zones, EVA suits and
carrying supplies, and an atmosphere model with temperature. It also replaces the `Try*` space
weather calls with status structs. Most of the other new types are aerodynamic meshes, content
loading, editor history and rendering, which have no API.

The port to 5801 (PR pending) already moved the service to the new atmosphere and radiation calls.
`Body.ScaleHeight` became the sea-level scale height, a breaking change in v0.2.1.

## Game Surface

| Area | Key game types | New in 5801 |
| --- | --- | --- |

| Life support | `LifeSupport`, `LifeSupportForecast`, `Vehicle.LifeSupportForecast` | Air, water, food and CO2 scrubber per kitten, with time left and a level (Ok, Low, Critical, Out) |

| Incapacitated crew | `Vehicle.IsControllable`, `HasControlModule` | A crewed vehicle with every kitten incapacitated has no control unless it has a probe core |
| Crew moves | `Vehicle.MoveCrew`, `SetSeatCrew`, `CrewMoveResult`, `CrewSeatResult` | Moves stay inside a habitat zone, with a result code per refusal |
| EVA suits | `EvaSuit`, `SuitLoad`, `Vehicle.CheckEva`, `OutsideAir` | A suit is filled from the zone on EVA, and returned on boarding. EVA is refused without suit supplies |

## Proposed API

### 1. Atmosphere

KSP's `Flight` names are reused where the meaning matches.

| Class | Members | Game source |
| --- | --- | --- |
| `Flight` | `StaticAirTemperature`, `SpeedOfSound`, `Mach` | `PhysicsEnvironment.AtmosphericTemperature`, `SpeedOfSound` |
| `Flight` | `OutsideAir`, an `OutsideAir` enum (no atmosphere, no oxygen, too thin, breathable) | `Vehicle.GetOutsideAir` |
| `Body` | `TemperatureAt(altitude)`, `SpeedOfSoundAt(altitude)` | `PhysicalAtmosphere.ComputeTemperatureAtAltitude`, `AtmosphericMixture.ComputeSpeedOfSound` |
| `Body` | `AtmosphereOxygenFraction`, `AtmosphereMolarMass` | `PhysicalAtmosphere.OxygenVolumeFraction`, `AtmosphericMixture.MolarMass` |

The *Absent in KSA* row "Air temperature, Mach" in [api-coverage.md](api-coverage.md) is then
filled.

### 2. Life Support

| Class | Members | Game source |
| --- | --- | --- |
| `KSA` | `LifeSupportEnabled`, `RadiationEnabled` (read-only) | `Universe.Rules` |
| `Vehicle` | `LifeSupport`, the worst zone's forecast | `Vehicle.LifeSupportForecast` |
| `Vehicle` | `HabitatZones` | `PartTree.HabitatZones` |
| `HabitatZone` | `Parts`, `Seats`, `Crew`, `HabitableVolume`, `StorageVolume`, `LifeSupport` | `HabitatZone`, `LifeSupport.ComputeZoneForecasts` |
| `LifeSupport` | `Kittens`, `AirMass`, `WaterMass`, `Meals`, `AirTime`, `WaterTime`, `FoodTime`, `ScrubberTime`, `Time`, `LimitingSupply`, `Level` | `LifeSupportForecast` |
| `Part` | `Habitat` | `Habitat` module |
| `Habitat` | `Zone`, `HabitableVolume`, `StorageVolume`, `Meals`, `Canisters`, `MaxMeals`, `MaxCanisters`, `IsStorage` | `Habitat.CountMeals`, `CountCanisters`, `ComputeFullLoad`, `EvaCarry.CheckStorage` |
| `Habitat` | `Transfer(to, meals, canisters)` | `Vehicle.TransferSupplies` |
| enums | `LifeSupportLevel` (ok, low, critical, out), `LifeSupportSupply` (air, scrubber, water, food) | Game enums |

`LifeSupport` is a snapshot struct-like class, as `Orbit` is for a patch. *Verify* whether meals and
canisters also show in `Part.Resources`, and whether `Debug.FillResources` fills them. If not,
`Debug` gets `FillSupplies` and `EmptySupplies` over `Habitat.RefillAll` and `DepleteAll`.

### 3. Kitten Condition

| Class | Members | Game source |
| --- | --- | --- |
| `Kitten` | `CauseOfDeath`, with a `DeathCause` enum of the game's 14 values | `KittenRosterEntryData.CauseOfDeath` |
| `Kitten` | `TimeWithout(supply)`, `Condition(supply)`, `WorstCondition` | `KittenCondition.GetSecondsWithout`, `GetRung`, `GetWorstRung` |
| `Kitten` | `Incapacitated`, `EvaReadiness` | `KittenCondition.IsIncapacitated`, `GetEvaReadiness` |
| enum | `KittenCondition` (healthy, warning, degraded, incapacitated, dead) | `LifeSupportRung` |
| `Vehicle` | `Controllable`, `HasControlModule` | `Vehicle.IsControllable`, `HasControlModule` |

`Controllable` explains an auto-pilot or control input with no effect, which a script cannot detect
today.

### 4. Crew, EVA and Carrying

| Class | Members | Game source |
| --- | --- | --- |
| `Seat` | `Kitten` setter moves a kitten aboard through the zone rules, and throws with the result | `Vehicle.MoveCrew`, `SetSeatCrew` |
| `Kitten` | `CanGoOnEva`, with `GoOnEva` throwing the reason | `Vehicle.CheckEva`, `EvaCheck` |
| `Kitten` | `Suit` on EVA: air time, scrubber time, water, meals | `EvaSuit.ReadLoad` |
| `Kitten` | `CanBoard`, with `Board` throwing the reason | `KittenEva.CheckBoarding`, `FindBoardTarget` |
| `Kitten` | `CarriedMeals`, `CarriedCanisters`, `Take(habitat, meals, canisters)`, `Stow(habitat, meals, canisters)` | `KittenEva.Carry`, `CheckCarry`, `FindReachableStorage` |
| `DockingPort` | `HatchOpen` (rw) | `DockingPort.HatchOpen` |

The `Can*` members return a boolean, so a script can check before it acts. The reason goes in the
exception text, which keeps the game's result enums out of the API.

### 5. Space Weather

Deferred in [api-coverage.md](api-coverage.md) because the model churned through 5707. 5801 settles
the call shapes, but the model has not been checked for stability across a second build.

| Class | Members | Game source |
| --- | --- | --- |
| `Flight` | `SolarWindSpeed`, `SolarWindPressure`, `SolarWindNorthwardField` | `Radiation.ComputeSolarWindAt` |
| `KSA` | Coronal mass ejections in flight, with arrival time and speed at a vehicle | `Eruptions`, `CmeFlight.GetArrival` |

Deferred until the next KSA build shows whether these calls change again.

## Phases

Each merges on its own, with in-game tests, in the order above. Phase 1 needs no new test content.
Phases 2 to 4 need a scenario where supplies run low. `Debug` empties a habitat, then the tests
warp to a level change. Phase 3 depends on phase 2 for its tests.

| Phase | Size | Tests |
| --- | --- | --- |
| 1. Atmosphere | Small | Temperature and Mach on the Rocket's ascent profile, against the body model |
| 2. Life support | Medium | Gemini7 forecasts, zones, transfers between habitats |
| 3. Kitten condition | Small | Empty supplies, warp, check rungs and incapacitated control |
| 4. Crew, EVA, carrying | Medium | Zone moves, EVA refusal without supplies, take and stow at Gemini7 |
| 5. Space weather | Deferred | |

## Built Differently

| Phase | Change | Why |
| --- | --- | --- |
| 1 | `Flight.StaticAirTemperature` and `SpeedOfSound` come from the body's atmosphere at the vehicle's altitude | The game's physics environment leaves both stale outside the physics radius |
| 2 | `LifeSupport` gives `TimeToNextLevel`, and computes the forecast on each read | The game updates its forecast once a frame, which is empty in the frame after a kitten goes on EVA |
| 2 | `Vehicle.Habitats` and `Part.Habitats` lists, `Habitat.MealCapacity` and `CanisterCapacity`, no `IsStorage` | As the power modules. A habitat with no storage volume has capacity zero |
| 2 | A `HabitatZone` is identified by its first habitat | The game rebuilds its zones when the vehicle changes |
| 2 | `Debug.FillResources` and `EmptyResources` cover meals and canisters | The game's commands empty every substance store, habitats included |
| 3 | `Kitten.CauseOfDeath` is `null` for a living kitten. `EvaReadiness` dropped | `WorstCondition` and `CanGoOnEva` cover it |
| 4 | The suit is `Kitten.LifeSupport`, a `LifeSupport` like a vehicle's | The game forecasts a suit as a one-kitten habitat zone |
| 4 | `Take`, `Stow` and `CanCarry(habitat)` on `Kitten` | One method per direction, as the game's carry window has one button each |
| 4 | `Board` keeps its one error | The game's board target search skips doors without a free seat before it checks range |

Tests use a `SupplyTest` vehicle, Gemini7's capsule with an empty supply locker in place of its
docking port, so both habitats share a zone. The game stops a time warp when supplies run out and
when a kitten's condition worsens, so `KSA.WarpTo` returns early then.

## Decisions

| Question | Decision |
| --- | --- |
| `KSA.LifeSupportEnabled` and `RadiationEnabled` writable? | Read-only. The game sets them when a save is created |
| Result enums (`CrewMoveResult`, `EvaCheck`, `BoardingCheck`, `CarryCheck`) in the API? | No. A boolean `Can*` plus the reason in the exception |
| One `LifeSupport` class for vehicle, zone and suit forecasts? | Yes. The game uses one `LifeSupportForecast` for all three |
| Space weather in this round? | No. Revisit at the next KSA build |
